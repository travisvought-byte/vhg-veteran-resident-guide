# Private directory prototype

Open index.html directly in a browser. It embeds the 66-resource safe projection so search works without a server. prototype-data.json contains the same projected records. Internal contacts and provenance are excluded from this projection. The original working research remains private in this package.

Search, county/type/evidence filters, county-office shortcut, reset and print are included. County filters include statewide resources. No public deployment, GitHub repository or outreach has been performed.
