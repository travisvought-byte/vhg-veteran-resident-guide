Bingo in Montana

Groups and places in Montana with a current state license or permit for bingo, by county. The state list does not show game days, so call before you go.

Shows bingo near you in every state we cover, closest first.

Montana allows live bingo under permits from the state Gambling Control Division, which publishes a list of places that offer live keno or bingo. Many are bars, casinos and clubs. Montana live bingo permits come from the Department of Justice's Gambling Control Division, 406-444-1971.

Montana's list names places with a permit for live bingo. It does not show game days or times, so call before you go. Places the list shows only with a mailing address are not shown here; the state list has them.
